Standard Kandungan / Standard Pembelajaran
3.2.1 Mengenal bentuk, huruf, nombor, perkataan atau ayat.
3.2.2 Menyalin semula sesuatu bentuk, huruf, nombor, perkataan atau ayat.
Objektif (murid boleh...)
1. Mengenal bentuk, huruf, nombor, perkataan atau ayat secara berpandu.
2. Mengingat kembali dan menyalin bentuk, huruf, nombor, perkataan atau ayat.
Aras kesukaran
Aras 1 (Mudah): objektif 1, pilihan sedikit, model sentiasa kelihatan.
Aras 2 (Sederhana): objektif 1 dan 2, pilihan dan item bertambah, menyalin dengan model kelihatan.
Aras 3 (Sukar): objektif 2, murid mengingat kembali kerana model disembunyikan, dan item paling banyak.
